Binangonan disease surveillance

Double-click index.html. Works offline in Chrome or Edge. Keep the app files and assets together. Existing leptospirosis records remain in the same browser storage.

  1. Choose Leptospirosis or Dengue in the sidebar. Use New case to add a record; edit or delete through Case registry.
  2. Select the reporting year and Through MW. Dashboard and report use the same cutoff. Prior-year comparisons use the same morbidity weeks.
  3. Open Automatic thresholds. Confirm complete historical years, or enter verified weekly totals. Blank cells use the case registry only when the corresponding year is marked complete. A confirmed complete year with no case in a week contributes zero; an incomplete year contributes missing data.
  4. Save the historical baseline. Thresholds recalculate when historical cases change: alert = mean + 1 sample standard deviation; epidemic = mean + 2 sample standard deviations, using 3–5 previous years for each week. Current-year cases update chart bars but do not raise their own threshold. Historical totals, when entered, replace the weekly case-registry count; clear an override to use the registry again.
  5. For 2026 leptospirosis, the supplied Rizal curves are displayed as a clearly labelled provincial reference until municipal calculations become available. They are approximate chart values, not official Binangonan thresholds. Dengue starts without cases or thresholds because no local dengue dataset was supplied. Weeks without at least 3 historical values have no calculated threshold.
  6. Open Report & print, select week and signatories, then Print / Save as PDF. Leptospirosis: 4 pages—1 A4 landscape bulletin and 3 Long/Folio portrait detail pages (8.5 × 13 inches). Dengue: 3 pages—1 A4 landscape bulletin and 2 Legal portrait detail pages (8.5 × 14 inches). Use 100% scale, background graphics on, browser headers and footers off.
  7. Use Download data backup to save a JSON copy of both disease registries, historical baselines, and signatories. Records are stored only in this browser profile on this device. Keep the same file location and browser for continued access.

For dengue, the cluster marker means at least 3 reported cases in the same barangay across the last four morbidity weeks. It is a screening indicator, not an official hotspot declaration.

Threshold method: DOH PIDSR Manual, section 5.3.5. The app uses sample standard deviation (n−1); the cited manual states the mean-plus-SD method without specifying that denominator.
